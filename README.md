# まるしん公式ホームページ Ver.3

## 管理画面
公開URLの末尾に `/admin/` を付けて開きます。

例:
`https://marushin-arao.netlify.app/admin/`

## 管理画面で編集できる内容
- 基本設定
- イベント
- 活動報告
- フォトギャラリー
- ボランティア募集

## Netlify側で必要な設定
1. Identity を有効化
2. Identity → Services → Git Gateway を有効化
3. Identity → Registration preferences を「Invite only」にする
4. Identity → Invite users から管理者メールを招待
